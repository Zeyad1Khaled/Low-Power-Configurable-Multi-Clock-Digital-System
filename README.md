# Low-Power-Configurable-Multi-Clock-Digital-System
Designed and integrated a multi-clock RTL system including UART TX/RX, ALU, register file, asynchronous FIFO, clock divider, clock gating, synchronizers, and system controller. Validated with Verilog test bench, SpyGlass analysis, synthesized with Design Compiler, and completed full place-and-route flow in Cadence Innovus.
