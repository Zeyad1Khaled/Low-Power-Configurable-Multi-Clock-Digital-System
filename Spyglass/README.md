# SpyGlass

`lint_cdc.prj` is the retained SpyGlass project. It reads RTL and standard-cell
libraries from the repository and uses the waiver files in `waivers/`.

The latest consolidated results and run summaries for each completed goal are
in [`../reports/spyglass/`](../reports/spyglass/). Intermediate work
databases, caches, and duplicate report copies are not retained.
